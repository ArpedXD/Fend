About Us
Our team at Group N5XT consists of first year students who are passionate about developing simple and enjoyable web experiences. As a part of our school work, we built a mini game website inspired by Friv type of platforms.

The website contains 5 different games all of which aim to be simple so that anyone can play them and have a good time. The main focus of the project is to merge the ideas and programming skills of the team members while at the same time providing an interactive experience.

We intentionally kept the website layout simple so that users can easily move from one game to another and even see what else we have created.
